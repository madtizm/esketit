# Local Network Tester

This simple Flask web application allows testing IP addresses, subnets, domains, and ports. It supports four languages: English, Turkish, Russian, and Turkmen.

## Usage

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the application:
   ```bash
   python app.py
   ```
3. Open `http://localhost:5000` in your browser.

Choose a language from the links and enter an IP, subnet, domain, or port to test.
